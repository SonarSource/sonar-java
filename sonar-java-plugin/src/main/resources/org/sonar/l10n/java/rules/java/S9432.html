This rule raises an issue when code calls a method that removes leading and trailing whitespace from a string and then checks its length or emptiness to determine if the string contains only whitespace.

In Java, this specifically refers to the trim() and strip() methods.

Why is this an issue?

Invoking operations that create new string objects with whitespace removed incurs unnecessary memory allocation and management overhead. When the goal is simply to check if a string contains only whitespace, creating this intermediate string object is wasteful.

The following patterns are inefficient:

  • Removing whitespace from a string, then checking if the resulting string has zero length or is empty
  • Removing whitespace from a string, then checking if the result contains only whitespace (redundant since the whitespace removal operation already eliminates whitespace)

These checks create a temporary string object just to examine it, which is discarded immediately after the check completes.

In performance-sensitive code or when processing many strings, this inefficiency can accumulate, increasing memory pressure and CPU usage for memory management operations.

In Java specifically, this applies to patterns like string.trim().length() > 0, string.trim().isEmpty(), string.strip().length() > 0, string.strip().isEmpty(), or string.strip().isBlank().

What is the potential impact?

The performance impact of this issue depends on how frequently the code executes:

  • In tight loops or high-throughput services: The repeated allocation of temporary String objects can significantly increase memory consumption and garbage collection frequency, degrading application performance.
  • In typical application code: The impact is minor but still represents unnecessary overhead that accumulates over the application’s lifetime.

The issue also affects code readability. Using the appropriate whitespace-checking method makes the intent clearer than checking the length of a trimmed string.

In Java, the appropriate method is isBlank().

How to fix it

For Java 11 and later, replace trim/strip-based checks with the isBlank() method, which efficiently checks if a string contains only whitespace without creating intermediate objects.

Code examples

Noncompliant code example

public void validate(String input) {
    if (input != null && input.trim().length() > 0) { // Noncompliant
        process(input);
    }
}

Compliant solution

public void validate(String input) {
    if (input != null && !input.isBlank()) {
        process(input);
    }
}
