The ternary pattern a != null ? a.equals(b) : b == null is a verbose way to perform null-safe equality checks. Java provides Objects.equals(a, b) which handles null values and is clearer to read.

Why is this an issue?

Manual null-check-then-equals patterns are error-prone and harder to read than the standard library alternative. The java.util.Objects.equals() method was introduced in Java 7 specifically to simplify null-safe equality comparisons. Using it makes the intent immediately clear and eliminates the risk of mistakes in the null-handling logic.

Code examples

Noncompliant code example

boolean equal = a != null ? a.equals(b) : b == null; // Noncompliant

Compliant solution

boolean equal = Objects.equals(a, b);
