Classes should not extend a configured superclass.

Why is this an issue?

Extending a forbidden superclass can couple code to an implementation that the project does not support.

How to fix it

Code examples

Noncompliant code example

abstract class LoggingService extends Logger { // Noncompliant
}

Compliant solution

class LoggingService {
  private static final Logger LOGGER = LoggerFactory.getLogger(LoggingService.class);
}
