Controller request-mapping methods should not use JPA entities as parameters.

Why is this an issue?

Using an entity in a controller request mapping exposes persistence details in a web API.

How to fix it

Code examples

Noncompliant code example

@Controller
class OrderController {
  @RequestMapping
  void update(Order order) { // Noncompliant
  }
}

@Entity
class Order {
}

Compliant solution

@Controller
class OrderController {
  @RequestMapping
  void update(OrderRequest request) {
  }
}

class OrderRequest {
}
