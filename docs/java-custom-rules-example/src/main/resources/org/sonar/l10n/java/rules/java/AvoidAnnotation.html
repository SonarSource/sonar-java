Configured annotations should not be used.

Why is this an issue?

An annotation that is forbidden by a project rule can introduce an unwanted dependency or behavior.

How to fix it

Code examples

Noncompliant code example

class Service {
  @Inject
  void setDependency(Dependency dependency) { // Noncompliant
  }
}

Compliant solution

class Service {
  void setDependency(Dependency dependency) {
  }
}
