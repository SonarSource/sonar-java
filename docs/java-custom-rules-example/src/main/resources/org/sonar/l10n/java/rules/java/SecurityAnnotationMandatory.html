Methods in a secured interface implementation should have the required security annotation.

Why is this an issue?

Missing the required security annotation can leave a method without the expected protection.

How to fix it

Code examples

Noncompliant code example

class AccountService implements MySecurityInterface {
  void deleteAccount() { // Noncompliant
  }
}

Compliant solution

class AccountService implements MySecurityInterface {
  @MySecurityAnnotation
  void deleteAccount() {
  }
}
