Method names should not include a brand name.

Why is this an issue?

Brand names couple a method to one vendor and can make the code less reusable.

How to fix it

Code examples

Noncompliant code example

class ReportService {
  void exportForMyCompany() { // Noncompliant
  }
}

Compliant solution

class ReportService {
  void exportReport() {
  }
}
