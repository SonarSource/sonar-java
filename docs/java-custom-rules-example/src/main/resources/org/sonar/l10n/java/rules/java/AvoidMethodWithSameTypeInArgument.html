A method should not return the same type as its only parameter.

Why is this an issue?

A method with the same return type and parameter type can make its purpose unclear.

How to fix it

Code examples

Noncompliant code example

class Counter {
  int update(int value) { // Noncompliant
    return value + 1;
  }
}

Compliant solution

class Counter {
  void update(int value) {
  }
}
